## 1. 日落海整备流（自动化第 1）

推荐棋手：闹闹 > 香香 > 常小娥。

核心：狂铁 / 亚连 / 米莱狄 / 安琪拉整备 → 朵莉亚放大 → 海诺再放大阿科米亚核心。开团时核心等级以临时等级均分给日落海英雄（单英雄上限 50%）。

| 阶段 | 回合 | 棋手等级 | 场上 |
|---|---|---|---|
| 前期 | 1–3 | 第 2 回合升 2 级 | 狂铁；备选弈星、牛魔 |
| 中期 | 4–7 | 升 3 级 | 狂铁、亚连、米莱狄、安琪拉、朵莉亚（尽量觉醒） |
| 后期 | 8–11 | 升 5 级 | 加雅典娜、海诺 |
| 决赛 | 12+ | | 可上露娜；决赛圈可只留雅典娜 + 安琪拉或海诺 |

买牌顺序：狂铁 → 亚连/米莱狄 → 安琪拉/朵莉亚 → 雅典娜 → 海诺 → 露娜。

站位（官方图转写）：后排亚连 D4、米莱狄 E4、安琪拉 F4；前排左朵莉亚 A2、狂铁 B2、海诺 C2；前排右雅典娜 G2。对面有闪现时包围安琪拉。

装备（官方站位图）：安琪拉 法源之杯 / 虚无法杖 / 炽热支配者；雅典娜 霸者重铠 / 近卫荣耀 / 不死鸟之眼。商店出现「远洋宝藏」则买。

天赋优先：智能装甲、能量汲取、日落海新援、日落海来客、积极整备。

转阵：4–7 仍无朵莉亚且无安琪拉时，继续低阶整备并升 3 级找 3 费层 30%；官方未给必须转阵的截止回合。无海诺可用安琪拉当 C。无雅典娜用「日落海来客」或露娜补触发。

克制：官方只写防闪现切后。无官方克制表。

证据：官方新手指引日落海图文 + 官网 + wiki 英雄/天赋。闹闹技能开局选日落海后每回合 1 能量拿 1 张该阵营牌。

## 2. 嫦娥四人队 / 马瑶经典（自动化第 2）

推荐棋手：常小娥。官网：凑齐 4 人后每回合靠棋手技能成长，操作难度低。

核心 4 人：苏烈（1 阶前排，牺牲永久 +2 级）+ 瑶（开团分享首件普通装备并附身）+ 马超（吃队友控制回能与暴击）+ 海月（5 阶牺牲困敌方最高等级）。

站位与装备来自 wiki 马瑶经典 early（官网无 cell）：

| cell | 英雄 | 装备 |
|---|---|---|
| E2 | 苏烈 | 近卫荣耀、反伤重甲、极寒风暴 |
| E3 | 马超 | 自然法杖、不死鸟之眼、魔律之刃 |
| F3 | 瑶 | 破茧之衣、近卫荣耀 |
| D2 | 海月 | 聚灵水晶、魔律之刃、不死鸟之眼 |

维持 4 人，不为扩人口而铺低质量牌（小菟随机助力会被稀释）。场上满 4 人后再打小菟送福。秘技门槛以官网为准：等级总和 50 / 150 / 375（chessplayerFacts 写作 50/175/400，已弃用）。

替补：海月不来用裴擒虎或走苏虎震月（裴擒虎、海月、苏烈、司空震）。

转阵：不为找马超无上限刷新（刷新消耗未知）。3 人也能吃技能。

证据：官网新人推荐 + wiki early。官方四人队卡图第 4 人外形接近裴擒虎，与 wiki 海月方案并存，主方案用海月。

## 3. 大河图腾流（自动化第 3）

推荐棋手：瑶妹 > 香香 > 常小娥。官网：凑齐后全员自动成长。

图腾链：鬼谷子先知图腾 + 少司缘因缘图腾 + 大司命往生图腾 → 虞姬按图腾数开团加等级、张良每次开团给随机 3 人永久等级 → 敖隐按图腾叠攻速与临时等级 → 东皇让图腾不优先被攻击。

| 阶段 | 回合 | 动作 |
|---|---|---|
| 1–3 | 升 2 级 | 牛魔、干将莫邪过渡 |
| 4–7 | 先 3 后 4 | 免费刷新找虞姬、鬼谷子、张良、少司缘；四人各 1 张后升 4 找大司命；输出装给虞姬 |
| 8–11 | 升 5 级 | 买敖隐、东皇、大司命；装备从虞姬转给敖隐；用英雄+图腾围住敖隐 |
| 12+ | | 觉醒；可上太乙真人或瑶；决赛可卖张良换太乙 |

天赋：复印机（复制 1–3 阶）、大河新援、大河精兵。不要优先「大河来客」（直接给刘邦，开团摧毁全部图腾）。

转阵：缺图腾召唤者则先打虞姬单核。无敖隐则装备留虞姬。无东皇用小鹿/瑶/太乙补前排。

克制：官方写防切敖隐。卡面层刘邦拆图腾是机制克制。无官方对局克制表。
